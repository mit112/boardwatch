# Architecture review — 2026-09-04 (D-467)

A read-only review of the whole source tree, done while run 2 was in flight. Six subsystem passes
(fetch/scan, store, orchestration, eligibility/rank, résumé pipeline, tests/CLI/web); every finding
marked **confirmed** was re-read or re-probed by the orchestrating session, **plausible** ones were
not. Line numbers are as of `3d15e086`. The owner's ruling: fix these in the next session, in the
order of the "fix first" list. **The PR-sized, ranked tickets are in `TICKETS-2026-09-04.md`.**

## Fix first (owner-ruled order)

1. **`store/db.py` engine has no `begin` hook** — the pysqlite driver defers BEGIN to the first DML, so
   every read-then-write (ledger dispositions, identity writes, regroup merges, `finish_run`) runs its
   reads in autocommit and can interleave with the CLI or the web viewer. D-426 met this and answered
   per site (two hand `BEGIN IMMEDIATE`s, "prefer one statement"); the documented engine-level fix is
   the `connect` (`isolation_level = None`) + `begin` (`BEGIN`) listeners. After it, the two hand
   sites must drop their own BEGIN. **Confirmed. High.**
2. **The résumé path fails OPEN on the template** — `tailor/render/latex.py:93-107`: the renderer never
   emits `Resume.header`/`.education`; they come only from `{config_dir}/resume_template.tex`, and if
   that file is absent `resolve_template` silently uses the bundled default whose header is literally
   "Your Name / 555 555 5555 / you@example.com / Example University". `_validate_template`
   (TODO/FIXME/lorem/ipsum/XXX/`<placeholder>`) does not catch it. The reset deleted exactly that
   file. **Confirmed. Critical (design).** Fix: refuse to render when the shell's header/education
   are not what the template prints, or render them from the model.
3. **Two keystone violations in `experience_years`** (`eligibility/rules.yaml`), probed end to end with
   a 1-year profile and an all-blocker policy:
   - "You must have **no less than** 5 years of experience" → **eligible** (bare `no` in
     `negation_cues` swallows it; "at least 5 years" → ineligible). **Critical.**
   - "at least **18 months** of experience" → **eligible** (every pattern requires `years?`). **High.**
4. **`delivery/queue.py:90` hardcodes the queue root** (`~/boardwatch-queue`) with no override on
   `run` (only `web` has `--queue-root`); a run against a scratch `BOARDWATCH_DATA_DIR` reconciles the
   owner's REAL queue with the scratch store as authority (consolidation rmtree, drains, pulling
   leads back out of `_applied`). **Confirmed. High.**

## Macro shape

81k source lines, 128k test lines (~9,400 tests), 49k lines of program docs, 1,327 commits in about
two months, 13 runtime dependencies. `profile_bundle` is 36k lines (44%) feeding an 84-line
`tailor.model.Resume`, two of whose five fields are dead (item 2). `run_pipeline` is 1,019 lines,
`rank_open_postings` 497, `build_run_funnel` 492, `funnel_to_markdown` 452. 62 closed string enums,
43 typed-violation raise sites, 48 exception classes: the closed-catalog doctrine is right for "never
silently drop a job" and it multiplies surface — each new failure mode is five edits.

The recurring pattern is symptom-level fixing: D-426's snapshot bug, the location substring bug, the
negation cue and the queue root were each fixed or documented where they surfaced and left in the
mechanism. The decision log records the reasoning faithfully, which is why the root causes are
findable at all.
